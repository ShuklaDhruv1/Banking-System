## 🏦 About the Project

**Banking System** is a Java console application created for learning Object-Oriented Programming, file storage, and input validation.

It simulates basic bank account operations using local files. It is an educational project, not a real banking application.

## ⚡ Features

- 🆕 Create bank accounts
- 📋 View all accounts
- 🔎 Check account balance
- 💰 Deposit money
- 💸 Withdraw money
- 🛡️ Validate transaction amounts
- 💾 Save account data in a text file
- 🔄 Load saved accounts after restarting
- ⚠️ Handle invalid numeric inputs

## 🧠 Concepts Used

| Concept | Purpose |
|---|---|
| Classes and Objects | Represent bank accounts |
| Encapsulation | Protect account fields |
| ArrayList | Store accounts in memory |
| Methods | Organize banking operations |
| File Handling | Read and write account data |
| Exception Handling | Handle invalid inputs |
| Validation | Reject invalid transaction amounts |

## 📂 Project Structure

```text
Banking-System/
├── BankAccount.java
├── BankFileHandler.java
├── BankingSystem.java
├── accounts.txt
└── README.md
```

`accounts.txt` is created locally when account data is saved.

## 🚀 How to Run

**Compile all Java files:**

```bash
javac BankAccount.java BankFileHandler.java BankingSystem.java
```

**Start the application:**

```bash
java BankingSystem
```
